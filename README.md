# Portfolio

A modern, interactive portfolio application built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

## Features

- Dynamic Sections: Hero, About, Projects, Experience, Skills, Certifications, and Contact
- Interactive UI animations with Framer Motion
- Custom cursor & themes
- Built with React + TypeScript + Vite
